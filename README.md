# Time Duration Calculator Java

A simple Java-based Time Duration Calculator that calculates the total duration between two time values in hours, minutes, and seconds.

## Features

- Enter start time
- Enter end time
- Calculate duration in hours
- Calculate duration in minutes
- Calculate duration in seconds
- Supports duration across midnight
- Validates time values
- Simple console-based interface

## Technologies Used

- Java
- Scanner
- Conditional Statements
- Arithmetic Operations

## How to Run

Compile the program:

javac TimeDurationCalculator.java

Run the program:

java TimeDurationCalculator
